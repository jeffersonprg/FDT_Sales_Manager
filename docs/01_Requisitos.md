# FDT Sales Manager

## Autor

Jefferson Gomes

## Objetivo

Desenvolver uma aplicação desktop em Python para análise de dados de vendas e gestão comercial da empresa FDT (Formadores Day Traders).

---

# Requisitos fornecidos

O sistema deverá:

- Ler ficheiros CSV contendo dados de vendas;
- Analisar os dados;
- Gerar estatísticas;
- Apresentar uma interface gráfica;
- Gerar um relatório em HTML.

Para nota máxima:

- Mini CRM
- Gestão de Leads
- Gestão de Clientes
- Gestão de Produtos
- Gestão de Pedidos
- Gestão de Faturação

---

# Resposta do orientador

Não existe preferência relativamente à interface gráfica.

O ficheiro CSV deverá ser definido pelo próprio aluno.

Campos mínimos:

- Nome do cliente
- Morada
- Informação do cliente
- Pedidos
- Faturação
- Produtos

---

# Objetivo do projeto

Será desenvolvido um sistema de gestão comercial (MiniCRM) que também será capaz de importar ficheiros CSV, analisar vendas e gerar relatórios.

O analisador de vendas será uma funcionalidade integrada no sistema.
