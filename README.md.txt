# FDT Sales Manager

## Descrição

Aplicação desktop desenvolvida em Python para análise de dados de vendas e gestão comercial (MiniCRM), criada como projeto de estágio.

## Tecnologias

- Python
- CustomTkinter
- SQLite
- Pandas
- Matplotlib
- Jinja2
- Pillow

## Funcionalidades previstas

- Gestão de clientes
- Gestão de produtos
- Gestão de pedidos
- Gestão de leads
- Importação de CSV
- Relatórios HTML
- Dashboard
- Estatísticas de vendas
